# ML Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn raw Kaggle data into evaluated, exportable recommender files: game catalog, CF neighbours, content neighbours, tuned hybrid settings and a metrics table. Everything runs from one `dvc repro`.

**Architecture:** Plain functions in `src/steamrec/`, each tested on tiny hand-checkable data. Thin scripts in `pipeline/` call them and are wired together with `dvc.yaml`. One catalog index is shared by everything: **row i of `catalog.parquet` is game i** in every matrix. Neighbour lists are sparse matrices of shape `(n_games, n_games)`, keeping the top-K per row. Notebooks explore and sanity-check each step by calling the same functions.

**Tech Stack:** Python 3.11, pandas, numpy, scipy.sparse, scikit-learn (TF-IDF), sentence-transformers (pipeline only), pandera, PyYAML, DVC, pytest, uv.

**Spec:** `docs/design-decisions.md` (sections 3–5) and `docs/coding-standards.md`. Read both first. `CLAUDE.md` holds the short rule list.

## Global Constraints

- Plain code: rules in `docs/coding-standards.md` §14–15. Every vectorised numpy/scipy line gets a shape comment.
- Every tunable number lives in `params.yaml`, loaded once by `load_params()` and passed in as an argument.
- `cf.py` and `content.py` never import each other. Shared helpers live in `neighbours.py` (top-K) and `data.py` (catalog index).
- `content.py` imports `sentence_transformers` **inside** `embed_texts()` only, so tests and the API never need torch.
- Filter: positive reviews only, drop duplicate `(user_id, app_id)`, keep users with **5 to 168** positive reviews, then games with **≥ 50** positive reviews from those users.
- Catalog: games with **at least one tag** (~49.6k). Seeds: games with CF data (popularity > 0 in training).
- Confidence: `1 + c · log(1 + hours)`. Shrunk cosine: `cos · n / (n + λ)`.
- Content: TF-IDF over tags plus `all-MiniLM-L6-v2` embeddings of `"title: description"`. Games without a description use tags only.
- Hybrid: `alpha(g) = alpha_max · n_g / (n_g + halfpoint)`, `score = alpha · cf + (1 − alpha) · content`, each part scaled to [0, 1] first.
- Evaluation: held-out users, 3 seeds each, Recall@10, NDCG@10, coverage. Baselines: popularity, CF-only, content-only, hybrid. Tuning on validation users, final numbers on test users.
- Commit messages: plain sentence, no `feat:` prefix (`docs/coding-standards.md` §16).
- Run everything through uv: `uv run pytest`, `uv run python pipeline/...`.

## Review Focus

- **A seed with no CF neighbours** (game outside the CF set): recommendations still come back from content, and "because" points to the seed that matched on content. Test in Task 6.
- **Every candidate scores zero** (seed has no neighbours at all): still return k games, ties broken by popularity, never an empty list. Test in Task 6.
- **The same seed passed twice** (`[12, 12, 40]`): treated as two seeds, not three; never recommended back. Test in Task 6.
- **A description that is only whitespace or invisible characters** (e.g. `"  "`): treated as missing, so the game uses tags only. Test in Task 2.
- **A game pair with zero shared users:** similarity is exactly 0, never NaN, even when shrinkage is small. Test in Task 4.

```python
"""Typed settings loaded from params.yaml."""

from dataclasses import dataclass
from pathlib import Path

import yaml


@dataclass
class FilterParams:
    min_user_reviews: int
    max_user_reviews: int
    min_game_reviews: int


@dataclass
class SplitParams:
    val_users: int
    test_users: int
    n_seeds: int
    random_seed: int


@dataclass
class CFParams:
    confidence_scale: float
    shrinkage: float
    top_k: int
    chunk_size: int


@dataclass
class ContentParams:
    tag_weight: float
    top_k: int
    chunk_size: int
    embedding_model: str
    batch_size: int


@dataclass
class HybridParams:
    alpha_max: float
    popularity_halfpoint: float


@dataclass
class EvaluateParams:
    k: int
    alpha_max_grid: list[float]
    halfpoint_grid: list[float]


@dataclass
class Params:
    filter: FilterParams
    split: SplitParams
    cf: CFParams
    content: ContentParams
    hybrid: HybridParams
    evaluate: EvaluateParams


def load_params(path: Path) -> Params:
    """Load params.yaml into typed dataclasses.

    A misspelled or missing key raises TypeError straight away,
    because each dataclass only accepts its exact field names.
    """
    with path.open() as file:
        raw = yaml.safe_load(file)

    params = Params(
        filter=FilterParams(**raw["filter"]),
        split=SplitParams(**raw["split"]),
        cf=CFParams(**raw["cf"]),
        content=ContentParams(**raw["content"]),
        hybrid=HybridParams(**raw["hybrid"]),
        evaluate=EvaluateParams(**raw["evaluate"]),
    )
    return params
```

```python
def clean_descriptions(descriptions: pd.Series) -> pd.Series:
    """Collapse every run of whitespace (including U+2028 line separators) into one space."""
    filled = descriptions.fillna("")
    # \s in Python regex also matches Unicode separators like U+2028
    collapsed = filled.str.replace(r"\s+", " ", regex=True)
    return collapsed.str.strip()


def build_catalog(games: pd.DataFrame, metadata: pd.DataFrame) -> pd.DataFrame:
    """Games with at least one tag. Row i of the result is game i everywhere downstream."""
    merged = games[["app_id", "title"]].merge(metadata, on="app_id", how="inner")
    tag_counts = merged["tags"].str.len()
    catalog = merged[tag_counts > 0].reset_index(drop=True)

    catalog["description"] = clean_descriptions(catalog["description"])
    catalog["has_description"] = catalog["description"].str.len() > 0
    return catalog[["app_id", "title", "tags", "description", "has_description"]]


def filter_interactions(
    recommendations: pd.DataFrame,
    catalog_app_ids: pd.Series,
    min_user_reviews: int,
    max_user_reviews: int,
    min_game_reviews: int,
) -> pd.DataFrame:
    """Keep positive reviews from active (not extreme) users, for games enough of them liked.

    One pass: users are filtered first, then games are counted among the kept users.
    """
    deduplicated = recommendations.drop_duplicates(subset=["user_id", "app_id"], keep="last")
    positive = deduplicated[deduplicated["is_recommended"]]
    in_catalog = positive[positive["app_id"].isin(catalog_app_ids)]

    reviews_per_user = in_catalog.groupby("user_id")["app_id"].transform("size")
    keep_user = (reviews_per_user >= min_user_reviews) & (reviews_per_user <= max_user_reviews)
    active = in_catalog[keep_user]

    reviews_per_game = active.groupby("app_id")["user_id"].transform("size")
    kept = active[reviews_per_game >= min_game_reviews]
    return kept[["user_id", "app_id", "hours"]].reset_index(drop=True)


def split_users(
    interactions: pd.DataFrame, n_val: int, n_test: int, min_reviews: int, random_seed: int
) -> tuple[pd.DataFrame, pd.DataFrame, pd.DataFrame]:
    """Hold out whole users for validation and test; everyone else is training data.

    Only users with at least min_reviews likes can be held out, so each one has
    enough games to split into seeds and hidden games.
    """
    reviews_per_user = interactions.groupby("user_id").size()
    eligible = reviews_per_user[reviews_per_user >= min_reviews].index.to_numpy()
    if len(eligible) < n_val + n_test:
        raise ValueError(
            f"only {len(eligible)} users have >= {min_reviews} reviews, need {n_val + n_test}"
        )

    rng = np.random.default_rng(random_seed)
    chosen = rng.choice(eligible, size=n_val + n_test, replace=False)
    val_user_ids = chosen[:n_val]
    test_user_ids = chosen[n_val:]

    is_val = interactions["user_id"].isin(val_user_ids)
    is_test = interactions["user_id"].isin(test_user_ids)
    train = interactions[~is_val & ~is_test].reset_index(drop=True)
    val = interactions[is_val].reset_index(drop=True)
    test = interactions[is_test].reset_index(drop=True)
    return train, val, test


def catalog_positions(app_ids: pd.Series, catalog_app_ids: pd.Series) -> np.ndarray:
    """Row number in the catalog for each app_id."""
    lookup = pd.Index(catalog_app_ids)
    positions = lookup.get_indexer(app_ids)  # -1 where the app_id is not in the catalog
    unknown = app_ids[positions == -1]
    if len(unknown) > 0:
        raise ValueError(f"app_ids not in catalog: {unknown.unique()[:10].tolist()}")
    return positions.astype(np.int64)
```

```python
"""Pipeline stage: raw files -> catalog + train/val/test interactions."""

import logging
from pathlib import Path

from steamrec.config import load_params
from steamrec.data import (
    build_catalog,
    filter_interactions,
    load_games,
    load_metadata,
    load_recommendations,
    split_users,
)
from steamrec.logs import setup_logging
from steamrec.validate import GAMES_SCHEMA, METADATA_SCHEMA, RECOMMENDATIONS_SCHEMA

REPO_ROOT = Path(__file__).resolve().parent.parent
RAW_DIR = REPO_ROOT / "data" / "raw"
PROCESSED_DIR = REPO_ROOT / "data" / "processed"

logger = logging.getLogger(__name__)


def main() -> None:
    """Validate raw data, build the catalog, filter and split interactions."""
    params = load_params(REPO_ROOT / "params.yaml")

    games = GAMES_SCHEMA.validate(load_games(RAW_DIR))
    metadata = METADATA_SCHEMA.validate(load_metadata(RAW_DIR))
    recommendations = RECOMMENDATIONS_SCHEMA.validate(load_recommendations(RAW_DIR))

    catalog = build_catalog(games, metadata)
    logger.info("catalog: %d games with tags", len(catalog))

    interactions = filter_interactions(
        recommendations,
        catalog["app_id"],
        min_user_reviews=params.filter.min_user_reviews,
        max_user_reviews=params.filter.max_user_reviews,
        min_game_reviews=params.filter.min_game_reviews,
    )
    logger.info(
        "interactions: %d, users: %d, games: %d",
        len(interactions),
        interactions["user_id"].nunique(),
        interactions["app_id"].nunique(),
    )

    # held-out users need n_seeds seeds plus at least 2 hidden games
    min_reviews_held_out = params.split.n_seeds + 2
    train, val, test = split_users(
        interactions,
        n_val=params.split.val_users,
        n_test=params.split.test_users,
        min_reviews=min_reviews_held_out,
        random_seed=params.split.random_seed,
    )
    logger.info("train rows: %d, val rows: %d, test rows: %d", len(train), len(val), len(test))

    PROCESSED_DIR.mkdir(parents=True, exist_ok=True)
    catalog.to_parquet(PROCESSED_DIR / "catalog.parquet", index=False)
    train.to_parquet(PROCESSED_DIR / "train.parquet", index=False)
    val.to_parquet(PROCESSED_DIR / "val.parquet", index=False)
    test.to_parquet(PROCESSED_DIR / "test.parquet", index=False)


if __name__ == "__main__":
    setup_logging()
    main()
```

```python
"""Keep only each game's strongest neighbours. Shared by cf.py and content.py."""

import numpy as np
from scipy.sparse import csr_matrix


def keep_top_k(scores: np.ndarray, top_k: int) -> csr_matrix:
    """Keep the top_k largest positive scores in each row, as a sparse matrix."""
    n_rows, n_cols = scores.shape
    k = min(top_k, n_cols)

    # (n_rows, k): column positions of the k largest scores in each row (not sorted)
    top_columns = np.argpartition(-scores, k - 1, axis=1)[:, :k]
    # (n_rows, k): the scores at those positions
    top_scores = np.take_along_axis(scores, top_columns, axis=1)
    # (n_rows * k,): row number for each kept score
    row_numbers = np.repeat(np.arange(n_rows), k)

    kept = csr_matrix(
        (top_scores.ravel().astype(np.float32), (row_numbers, top_columns.ravel())),
        shape=(n_rows, n_cols),
    )
    kept.data[kept.data < 0] = 0.0  # similarity below zero means "not a neighbour"
    kept.eliminate_zeros()
    return kept
```

```python
"""Item-to-item collaborative filtering: people who liked X also liked Y."""

import numpy as np
import pandas as pd
from scipy.sparse import coo_matrix, csr_matrix, vstack

from steamrec.neighbours import keep_top_k


def confidence_from_hours(hours: np.ndarray, confidence_scale: float) -> np.ndarray:
    """How much one like counts, based on hours played."""
    # confidence = 1 + c * log(1 + hours); the log stops 1,000-hour players dominating
    return 1.0 + confidence_scale * np.log1p(hours)


def build_game_user_matrix(
    game_positions: np.ndarray, user_ids: np.ndarray, confidence: np.ndarray, n_games: int
) -> csr_matrix:
    """Sparse matrix with one row per catalog game and one column per training user."""
    user_columns, unique_users = pd.factorize(user_ids)
    n_users = len(unique_users)
    # (n_games, n_users): value = confidence of that user's like
    game_user = coo_matrix(
        (confidence.astype(np.float32), (game_positions, user_columns)), shape=(n_games, n_users)
    )
    return game_user.tocsr()


def similar_games(game_user: csr_matrix, shrinkage: float, top_k: int, chunk_size: int) -> csr_matrix:
    """Shrunk cosine similarity between games, keeping each game's top_k neighbours.

    Works on chunk_size games at a time so the dense block fits in memory.
    """
    n_games = game_user.shape[0]
    # (n_games,): length of each game's confidence vector
    norms = np.sqrt(np.asarray(game_user.multiply(game_user).sum(axis=1)).ravel())
    # (n_games, n_users): 1 where the user liked the game
    liked = (game_user > 0).astype(np.float32)

    blocks = []
    for start in range(0, n_games, chunk_size):
        stop = min(start + chunk_size, n_games)
        # (chunk, n_users) @ (n_users, n_games) -> (chunk, n_games): confidence dot products
        dots = (game_user[start:stop] @ game_user.T).toarray()
        # (chunk, n_users) @ (n_users, n_games) -> (chunk, n_games): users who liked both
        n_common = (liked[start:stop] @ liked.T).toarray()
        # (chunk, 1) * (1, n_games) -> (chunk, n_games): product of the two vector lengths
        norm_products = norms[start:stop, np.newaxis] * norms[np.newaxis, :]

        cosine = np.zeros_like(dots)
        np.divide(dots, norm_products, out=cosine, where=norm_products > 0)
        # shrunk cosine: sim * n / (n + λ); pairs with n = 0 stay exactly 0
        shrunk = cosine * n_common / (n_common + shrinkage)

        chunk_rows = np.arange(stop - start)
        shrunk[chunk_rows, start + chunk_rows] = 0.0  # a game is not its own neighbour
        blocks.append(keep_top_k(shrunk, top_k))

    return vstack(blocks).tocsr()


def game_popularity(game_positions: np.ndarray, n_games: int) -> np.ndarray:
    """Number of training likes per catalog game."""
    # (n_games,): count of each position
    return np.bincount(game_positions, minlength=n_games).astype(np.int64)
```

```python
"""Pipeline stage: training likes -> CF neighbours + game popularity."""

import logging
from pathlib import Path

import numpy as np
import pandas as pd

from steamrec.artifacts import save_matrix
from steamrec.cf import build_game_user_matrix, confidence_from_hours, game_popularity, similar_games
from steamrec.config import load_params
from steamrec.data import catalog_positions
from steamrec.logs import setup_logging

REPO_ROOT = Path(__file__).resolve().parent.parent
PROCESSED_DIR = REPO_ROOT / "data" / "processed"
MODELS_DIR = REPO_ROOT / "models"

logger = logging.getLogger(__name__)


def main() -> None:
    """Build the game-user matrix from training users and compute neighbours."""
    params = load_params(REPO_ROOT / "params.yaml")
    catalog = pd.read_parquet(PROCESSED_DIR / "catalog.parquet", columns=["app_id"])
    train = pd.read_parquet(PROCESSED_DIR / "train.parquet")
    n_games = len(catalog)

    game_positions = catalog_positions(train["app_id"], catalog["app_id"])
    confidence = confidence_from_hours(train["hours"].to_numpy(), params.cf.confidence_scale)
    game_user = build_game_user_matrix(
        game_positions, train["user_id"].to_numpy(), confidence, n_games
    )
    logger.info("game-user matrix: %s, %d likes", game_user.shape, game_user.nnz)

    neighbours = similar_games(
        game_user,
        shrinkage=params.cf.shrinkage,
        top_k=params.cf.top_k,
        chunk_size=params.cf.chunk_size,
    )
    logger.info("CF neighbours: %d stored similarities", neighbours.nnz)

    popularity = game_popularity(game_positions, n_games)
    save_matrix(MODELS_DIR / "cf_neighbours.npz", neighbours)
    np.save(MODELS_DIR / "popularity.npy", popularity)


if __name__ == "__main__":
    setup_logging()
    main()
```

```python
"""Content-based similarity from tags and descriptions."""

import numpy as np
import pandas as pd
from scipy.sparse import csr_matrix, vstack
from sklearn.feature_extraction.text import TfidfVectorizer

from steamrec.neighbours import keep_top_k


def tags_as_tokens(tags: list[str]) -> list[str]:
    """Each tag is one token; TfidfVectorizer calls this instead of splitting text."""
    return list(tags)


def tag_vectors(tags: pd.Series) -> csr_matrix:
    """TF-IDF over tag lists. Rows are unit length, so a dot product is the cosine."""
    vectorizer = TfidfVectorizer(analyzer=tags_as_tokens)
    # (n_games, n_tags)
    vectors = vectorizer.fit_transform(tags)
    return vectors.astype(np.float32).tocsr()


def embedding_texts(titles: pd.Series, descriptions: pd.Series) -> pd.Series:
    """Text to embed: the title helps series and sequels land near each other."""
    return titles + ": " + descriptions


def embed_texts(texts: list[str], model_name: str, batch_size: int) -> np.ndarray:
    """Sentence-transformer embeddings, unit length.

    Imported here, not at the top, so tests and the API never need torch.
    """
    from sentence_transformers import SentenceTransformer

    model = SentenceTransformer(model_name)
    embeddings = model.encode(
        texts, batch_size=batch_size, normalize_embeddings=True, show_progress_bar=True
    )
    return embeddings.astype(np.float32)


def place_embeddings(text_embeddings: np.ndarray, has_description: np.ndarray) -> np.ndarray:
    """Put each embedding on its game's catalog row; games without text get a zero row."""
    n_games = len(has_description)
    dim = text_embeddings.shape[1]
    placed = np.zeros((n_games, dim), dtype=np.float32)
    placed[has_description] = text_embeddings
    return placed


def content_similar_games(
    tags: csr_matrix,
    embeddings: np.ndarray,
    has_description: np.ndarray,
    tag_weight: float,
    top_k: int,
    chunk_size: int,
) -> csr_matrix:
    """Content similarity: blend of tag and text cosine, or tags only if a game has no text."""
    n_games = tags.shape[0]
    blocks = []
    for start in range(0, n_games, chunk_size):
        stop = min(start + chunk_size, n_games)
        # (chunk, n_tags) @ (n_tags, n_games) -> (chunk, n_games)
        tag_cosine = (tags[start:stop] @ tags.T).toarray()
        # (chunk, dim) @ (dim, n_games) -> (chunk, n_games)
        text_cosine = embeddings[start:stop] @ embeddings.T
        # (chunk, 1) & (1, n_games) -> (chunk, n_games): True where both games have text
        both_have_text = has_description[start:stop, np.newaxis] & has_description[np.newaxis, :]

        blended = tag_weight * tag_cosine + (1 - tag_weight) * text_cosine
        scores = np.where(both_have_text, blended, tag_cosine)

        chunk_rows = np.arange(stop - start)
        scores[chunk_rows, start + chunk_rows] = 0.0  # a game is not its own neighbour
        blocks.append(keep_top_k(scores, top_k))

    return vstack(blocks).tocsr()
```

```python
"""Blend CF and content scores into one ranking, with a 'because you liked' seed."""

from dataclasses import dataclass

import numpy as np
from scipy.sparse import csr_matrix

# Tiny popularity bonus: only decides ties (e.g. when every score is 0).
TIE_BREAK_WEIGHT = 1e-6


@dataclass
class Ranking:
    game_positions: np.ndarray
    scores: np.ndarray
    cf_scores: np.ndarray
    content_scores: np.ndarray
    because_positions: np.ndarray


def seed_scores(neighbours: csr_matrix, seed_positions: list[int]) -> tuple[np.ndarray, np.ndarray]:
    """Each game's summed similarity to the seeds, and which seed contributed most."""
    # (n_seeds, n_games): similarity of every game to each seed
    rows = neighbours[seed_positions].toarray()
    # (n_games,)
    totals = rows.sum(axis=0)
    # (n_games,): index into seed_positions of the strongest seed
    best_seed = rows.argmax(axis=0)
    return totals, best_seed


def scale_to_unit(scores: np.ndarray) -> np.ndarray:
    """Divide by the largest score so scores run from 0 to 1. All zeros stay zero."""
    largest = scores.max()
    if largest <= 0:
        return np.zeros_like(scores)
    return scores / largest


def alpha_per_game(popularity: np.ndarray, alpha_max: float, halfpoint: float) -> np.ndarray:
    """How much to trust CF for each game: more likes means more trust."""
    # alpha = alpha_max * n / (n + halfpoint); a game with halfpoint likes gets alpha_max / 2
    return alpha_max * popularity / (popularity + halfpoint)


def rank_games(
    cf_neighbours: csr_matrix,
    content_neighbours: csr_matrix,
    popularity: np.ndarray,
    seed_positions: list[int],
    alpha_max: float,
    halfpoint: float,
    k: int,
    alpha_override: float | None = None,
) -> Ranking:
    """Top k games for a visitor who liked the seed games."""
    unique_seeds = sorted(set(seed_positions))

    cf_totals, cf_best = seed_scores(cf_neighbours, unique_seeds)
    content_totals, content_best = seed_scores(content_neighbours, unique_seeds)
    cf_scores = scale_to_unit(cf_totals)
    content_scores = scale_to_unit(content_totals)

    if alpha_override is None:
        alpha = alpha_per_game(popularity, alpha_max, halfpoint)
    else:
        alpha = np.full(len(popularity), alpha_override)

    # (n_games,): the blend, plus a tiny popularity bonus that only breaks ties
    scores = alpha * cf_scores + (1 - alpha) * content_scores
    scores = scores + TIE_BREAK_WEIGHT * scale_to_unit(popularity)
    scores[unique_seeds] = -np.inf  # never recommend a game the visitor picked

    top = np.argsort(-scores)[:k]

    # "because": the seed behind the CF score if there is one, otherwise the content seed
    because_positions = []
    for game in top:
        if cf_totals[game] > 0:
            best = cf_best[game]
        else:
            best = content_best[game]
        because_positions.append(unique_seeds[best])

    return Ranking(
        game_positions=top,
        scores=scores[top],
        cf_scores=cf_scores[top],
        content_scores=content_scores[top],
        because_positions=np.array(because_positions),
    )
```

Note: `np.argsort` on ~50k games takes about 1 ms, fine for both evaluation and the API.

```python
"""Offline evaluation with simulated visitors: give 3 liked games, hide the rest."""

from collections.abc import Callable
from dataclasses import dataclass

import numpy as np
import pandas as pd


@dataclass
class Visitor:
    seeds: list[int]
    hidden: set[int]


@dataclass
class EvalResult:
    recall: float
    ndcg: float
    coverage: float


def recall_at_k(recommended: np.ndarray, hidden: set[int], k: int) -> float:
    """Share of hidden games found in the top k (capped so a perfect list scores 1)."""
    hits = 0
    for game in recommended[:k]:
        if game in hidden:
            hits += 1
    return hits / min(k, len(hidden))


def ndcg_at_k(recommended: np.ndarray, hidden: set[int], k: int) -> float:
    """Like recall, but a hit at rank 1 is worth more than a hit at rank 10."""
    # DCG = sum over hits of 1 / log2(rank + 1), rank starting at 1
    dcg = 0.0
    for rank, game in enumerate(recommended[:k], start=1):
        if game in hidden:
            dcg += 1.0 / np.log2(rank + 1)

    # ideal DCG: every top position is a hit
    ideal = 0.0
    for rank in range(1, min(k, len(hidden)) + 1):
        ideal += 1.0 / np.log2(rank + 1)
    return dcg / ideal


def coverage(recommended_lists: list[np.ndarray], n_games: int) -> float:
    """Share of the catalog that appears in at least one recommendation list."""
    seen = set()
    for recommended in recommended_lists:
        seen.update(recommended.tolist())
    return len(seen) / n_games


def make_visitors(
    game_positions: np.ndarray,
    user_ids: np.ndarray,
    popularity: np.ndarray,
    n_seeds: int,
    random_seed: int,
) -> list[Visitor]:
    """Turn held-out users into visitors: n_seeds random liked games as seeds, rest hidden.

    Seeds must have training likes (like the real search box). Users need at least
    one hidden game left over, otherwise they are skipped.
    """
    rng = np.random.default_rng(random_seed)
    likes = pd.DataFrame({"user_id": user_ids, "game": game_positions})

    visitors = []
    for _, user_likes in likes.groupby("user_id"):
        games = user_likes["game"].to_numpy()
        seedable = games[popularity[games] > 0]
        if len(seedable) < n_seeds or len(games) <= n_seeds:
            continue
        seeds = rng.choice(seedable, size=n_seeds, replace=False).tolist()
        hidden = set(games.tolist()) - set(seeds)
        visitors.append(Visitor(seeds=seeds, hidden=hidden))
    return visitors


def popular_games(popularity: np.ndarray, seeds: list[int], k: int) -> np.ndarray:
    """Baseline: the k most-liked games the visitor hasn't picked."""
    scores = popularity.astype(np.float64)
    scores[seeds] = -np.inf
    return np.argsort(-scores)[:k]


def evaluate_recommender(
    visitors: list[Visitor],
    recommend: Callable[[list[int]], np.ndarray],
    k: int,
    n_games: int,
) -> EvalResult:
    """Average Recall@k and NDCG@k over visitors, plus catalog coverage.

    recommend takes a visitor's seeds and returns game positions, best first.
    """
    recalls = []
    ndcgs = []
    all_lists = []
    for visitor in visitors:
        recommended = recommend(visitor.seeds)[:k]
        recalls.append(recall_at_k(recommended, visitor.hidden, k))
        ndcgs.append(ndcg_at_k(recommended, visitor.hidden, k))
        all_lists.append(recommended)

    return EvalResult(
        recall=float(np.mean(recalls)),
        ndcg=float(np.mean(ndcgs)),
        coverage=coverage(all_lists, n_games),
    )
```

```python
"""Pipeline stage: tune the hybrid on validation users, report everything on test users."""

import logging
from pathlib import Path

import numpy as np
import pandas as pd

from steamrec.artifacts import load_matrix, save_json
from steamrec.config import load_params
from steamrec.data import catalog_positions
from steamrec.evaluate import EvalResult, evaluate_recommender, make_visitors, popular_games
from steamrec.hybrid import rank_games
from steamrec.logs import setup_logging

REPO_ROOT = Path(__file__).resolve().parent.parent
PROCESSED_DIR = REPO_ROOT / "data" / "processed"
MODELS_DIR = REPO_ROOT / "models"

logger = logging.getLogger(__name__)


def load_visitors(path: Path, catalog_app_ids: pd.Series, popularity: np.ndarray, n_seeds: int, seed: int):
    """Read held-out users and turn them into visitors."""
    held_out = pd.read_parquet(path)
    game_positions = catalog_positions(held_out["app_id"], catalog_app_ids)
    return make_visitors(game_positions, held_out["user_id"].to_numpy(), popularity, n_seeds, seed)


def result_to_dict(result: EvalResult) -> dict:
    """Round metrics for metrics.json."""
    return {
        "recall_at_k": round(result.recall, 4),
        "ndcg_at_k": round(result.ndcg, 4),
        "coverage": round(result.coverage, 4),
    }


def main() -> None:
    """Grid-search alpha_max and halfpoint on val, then score all four recommenders on test."""
    params = load_params(REPO_ROOT / "params.yaml")
    k = params.evaluate.k
    catalog = pd.read_parquet(PROCESSED_DIR / "catalog.parquet", columns=["app_id"])
    n_games = len(catalog)
    cf = load_matrix(MODELS_DIR / "cf_neighbours.npz")
    content = load_matrix(MODELS_DIR / "content_neighbours.npz")
    popularity = np.load(MODELS_DIR / "popularity.npy").astype(np.float64)

    n_seeds = params.split.n_seeds
    seed = params.split.random_seed
    val_visitors = load_visitors(PROCESSED_DIR / "val.parquet", catalog["app_id"], popularity, n_seeds, seed)
    test_visitors = load_visitors(PROCESSED_DIR / "test.parquet", catalog["app_id"], popularity, n_seeds, seed)
    logger.info("visitors: %d val, %d test", len(val_visitors), len(test_visitors))

    # --- tune on validation users ---
    best_ndcg = -1.0
    best_alpha_max = params.hybrid.alpha_max
    best_halfpoint = params.hybrid.popularity_halfpoint
    for alpha_max in params.evaluate.alpha_max_grid:
        for halfpoint in params.evaluate.halfpoint_grid:

            def recommend(seeds: list[int]) -> np.ndarray:
                ranking = rank_games(cf, content, popularity, seeds, alpha_max, halfpoint, k)
                return ranking.game_positions

            result = evaluate_recommender(val_visitors, recommend, k, n_games)
            logger.info("alpha_max=%.2f halfpoint=%.0f ndcg=%.4f", alpha_max, halfpoint, result.ndcg)
            if result.ndcg > best_ndcg:
                best_ndcg = result.ndcg
                best_alpha_max = alpha_max
                best_halfpoint = halfpoint

    # --- final comparison on test users ---
    def recommend_hybrid(seeds: list[int]) -> np.ndarray:
        ranking = rank_games(cf, content, popularity, seeds, best_alpha_max, best_halfpoint, k)
        return ranking.game_positions

    def recommend_cf_only(seeds: list[int]) -> np.ndarray:
        ranking = rank_games(cf, content, popularity, seeds, 1.0, 1.0, k, alpha_override=1.0)
        return ranking.game_positions

    def recommend_content_only(seeds: list[int]) -> np.ndarray:
        ranking = rank_games(cf, content, popularity, seeds, 1.0, 1.0, k, alpha_override=0.0)
        return ranking.game_positions

    def recommend_popular(seeds: list[int]) -> np.ndarray:
        return popular_games(popularity, seeds, k)

    recommenders = {
        "popularity": recommend_popular,
        "cf_only": recommend_cf_only,
        "content_only": recommend_content_only,
        "hybrid": recommend_hybrid,
    }
    metrics = {"k": k, "test_visitors": len(test_visitors)}
    for name, recommend in recommenders.items():
        result = evaluate_recommender(test_visitors, recommend, k, n_games)
        metrics[name] = result_to_dict(result)
        logger.info("%s: %s", name, metrics[name])

    save_json(REPO_ROOT / "metrics.json", metrics)
    save_json(
        MODELS_DIR / "best_hybrid.json",
        {"alpha_max": best_alpha_max, "popularity_halfpoint": best_halfpoint},
    )


if __name__ == "__main__":
    setup_logging()
    main()
```

The functions defined inside loops are plain named functions, not lambdas. Each one is a recommender with the settings baked in, so `evaluate_recommender` can treat them all the same way.

### Task 9: Export the serving bundle

**Files:**
- Create: `pipeline/export.py`

**Interfaces:**
- Consumes: catalog, both neighbour files, popularity, `best_hybrid.json`, `metrics.json`.
- Produces: `models/serving/` containing `catalog.parquet` (`app_id, title, tags, popularity, is_seed`), `cf_neighbours.npz`, `content_neighbours.npz`, `manifest.json` (`created_at`, `n_games`, `hybrid` settings, `metrics`). The API plan will load exactly these.

- [ ] **Step 1: Write `pipeline/export.py`**

```python
"""Pipeline stage: copy everything the API needs into models/serving/."""

import logging
import shutil
from datetime import UTC, datetime
from pathlib import Path

import numpy as np
import pandas as pd

from steamrec.artifacts import load_json, save_json
from steamrec.logs import setup_logging

REPO_ROOT = Path(__file__).resolve().parent.parent
PROCESSED_DIR = REPO_ROOT / "data" / "processed"
MODELS_DIR = REPO_ROOT / "models"
SERVING_DIR = MODELS_DIR / "serving"

logger = logging.getLogger(__name__)


def main() -> None:
    """Write the small catalog, copy neighbour files, write the manifest."""
    SERVING_DIR.mkdir(parents=True, exist_ok=True)

    catalog = pd.read_parquet(PROCESSED_DIR / "catalog.parquet", columns=["app_id", "title", "tags"])
    popularity = np.load(MODELS_DIR / "popularity.npy")
    catalog["popularity"] = popularity
    catalog["is_seed"] = popularity > 0  # only games with CF data can be picked as seeds
    catalog.to_parquet(SERVING_DIR / "catalog.parquet", index=False)

    shutil.copy2(MODELS_DIR / "cf_neighbours.npz", SERVING_DIR / "cf_neighbours.npz")
    shutil.copy2(MODELS_DIR / "content_neighbours.npz", SERVING_DIR / "content_neighbours.npz")

    manifest = {
        "created_at": datetime.now(UTC).isoformat(timespec="seconds"),
        "n_games": len(catalog),
        "n_seed_games": int(catalog["is_seed"].sum()),
        "hybrid": load_json(MODELS_DIR / "best_hybrid.json"),
        "metrics": load_json(REPO_ROOT / "metrics.json"),
    }
    save_json(SERVING_DIR / "manifest.json", manifest)

    total_mb = 0.0
    for path in SERVING_DIR.iterdir():
        total_mb += path.stat().st_size / 1_000_000
    logger.info("serving bundle: %.1f MB in %s", total_mb, SERVING_DIR)


if __name__ == "__main__":
    setup_logging()
    main()
```
